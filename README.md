# Job Tracker AI

AI-powered job application tracker untuk mencatat dan memantau proses lamaran kerja melalui **web dashboard** dan **Telegram Bot**.

## ✨ Features

* 📝 Job application CRUD
* 🤖 Natural language input with Gemini AI
* 💬 AI Chat pada web dashboard
* 📱 Telegram Bot
* 🔎 Search & filter applications
* 📄 Pagination
* 📊 Application statistics
* ☁️ Production deployment

## 🛠️ Tech Stack

| Category   | Technology                               |
| ---------- | ---------------------------------------- |
| Frontend   | Next.js, React, TypeScript, Tailwind CSS |
| Backend    | Python, FastAPI, SQLAlchemy              |
| Database   | PostgreSQL                               |
| AI         | Gemini API                               |
| Bot        | Telegram Bot API                         |
| Deployment | Vercel, Render                           |
